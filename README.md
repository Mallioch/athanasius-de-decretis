# De Decretis

This is a repository for the Greek text of Athanasius.

## Base Text Source

The source for this text is [Joannes Carolus Thilo's (Johann Karl Thilo) 1853 edition](https://archive.org/details/operadogmaticase00atha/page/n9/mode/2up).

This text is in the public domain. The contributors do not recognize any rights gained from digitization.

The only intentional changes to the 1853 text are orthographical. Some examples:
* He has ὥςτε instead of our current pattern of ὥστε.
* He uses a rough breathing for Ἀβραάμ. This has been corrected. There are a few similar cases.

This text is in the `thilo` folder.

## Updated Text

There is another version of the text released under [the Creative Commons Attribution 4.0 International CC BY 4.0 Deed](https://creativecommons.org/licenses/by/4.0/deed.en). This includes the version of the text that will be used for an upcoming Greek reader's edition of the text. It is based on Thilo's text but contains changes. This text is contained in the folder named `updated`. The changes are mostly of the following nature:

* Corrections to accents.
* The addition of macrons.
* Changes to punctuation.
